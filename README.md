# Calcolatori Elettronici Exercises

Partial collection of exercises in MIPS assembly, from a course on Electronic Computers (Calcolatori Elettronici) that I took during my Bachelor's Degree in Electronic & Computer Engineering at the University of Ferrara.

## Usage

They can be run using [MARS](https://dpetersanderson.github.io/) (MIPS Assembler and Runtime Simulator)
